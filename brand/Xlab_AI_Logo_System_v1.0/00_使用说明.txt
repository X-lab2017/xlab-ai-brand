# X-lab AI 标志系统 · v1.0

## 先看什么、用什么

1. 打开「00_Logo_总览.png」核对本套正式交付文件。
2. 网站、PPT、文档、视频叠图：选择「01_PNG_透明底」中的对应背景版本。
3. 设计软件排版、需要放大使用：优先用「02_SVG_矢量描摹」。
4. 只想直接看到深浅背景效果：打开「03_背景预览」。这些 PNG 自带不透明背景，不适合直接叠加到照片上。
5. 社交平台头像和浏览器小图标：使用「04_应用图标」。
6. 「05_确认稿与历史素材」保留用户提供的四个 PNG、上一轮四个 AI 设计确认图，以及本轮系统适配概念示意；它们不是正式交付母版。

## 系统性核对结论

原标志已经包含浅底／深底两个方向：源文件 -02、-04 为深灰字，-03、-05 为透明底白字。白字文件放在白色查看器上看似缺字，是透明背景显示造成的，并非文字丢失。
上一轮 AI 设计给出了浅底横版、浅底竖版、独立图标和浅底单色示意，但未给出完整的深底反白组合、真正透明的独立交付文件和各版一致的矢量路径母版。
本次补齐如下完整矩阵，每一格均交付一个透明 PNG、一个 SVG 和一个自带背景的预览 PNG：

| 标志结构 | 浅底彩色 | 深底彩色 | 纯黑单色 | 纯白反白 |
| --- | --- | --- | --- | --- |
| 横版组合 Horizontal | 有 | 有 | 有 | 有 |
| 竖版组合 Vertical | 有 | 有 | 有 | 有 |
| 双语字标 WordmarkBilingual | 有 | 有 | 有 | 有 |
| 紧凑字标 WordmarkCompact | 有 | 有 | 有 | 有 |
| 独立灯泡图标 Symbol | 有 | 有 | 有 | 有 |

合计 20 个正式标志配置，提供 20 个 SVG、20 个透明 PNG、20 个背景预览。
独立灯泡没有灰色／白色文字，因此其浅底、深底彩色透明文件有意使用完全相同的图形及配色；区分文件名是为了便于按背景成套调用，不是漏做适配。

## 固定品牌表达

- 品牌名称：X-lab AI。
- AI 位于 X-lab 右上方，保留指数上标的视觉关系；不要把 AI 移到同一基线或改成普通后缀。
- 完整标志保留「开放实验室」；紧凑字标用于宽度有限的位置，主动省略中文副标。
- 灯泡的横向条带与负形 X、蓝色灯座、定制 X 字形及绿色切角均保留。
- 横版、竖版和字标使用同一组路径组件，不分别重新生成字形。深底版只转换灰色文字为白色，彩色部分保持原有品牌色。
- 原版字标／AI 的相对位置已固定在矢量路径中，不需要另行输入文字或安装字体。

## 配色

本次生产文件回归用户原标志中的三种主色，将生成图中的细微渐变与白底纹理统一为可重复使用的纯色。

| 角色 | sRGB 十六进制 | RGB |
| --- | --- | --- |
| 品牌绿：灯泡、X 切角、AI | #9AD744 | 154 / 215 / 68 |
| 品牌蓝：灯座 | #07A1D7 | 7 / 161 / 215 |
| 浅底字标灰 | #595757 | 89 / 87 / 87 |
| 深底字标白／纯白单色 | #FFFFFF | 255 / 255 / 255 |
| 纯黑单色 | #000000 | 0 / 0 / 0 |
| 预览推荐深底 | #171A1F | 23 / 26 / 31 |

浅底彩色用于白色或非常浅的背景；深底彩色用于深色背景；复杂图像背景应加纯色承载区，必要时使用纯黑或纯白单色版。SVG 和 PNG 中的负形 X、字腔及字间空白都是真正透明，不是画上去的白块。

## 留白与尺寸

- 本套正式文件已含统一的外围安全留白。以灯泡横条厚度 u 为参考，水平组合和独立灯泡的外围留白为 2u；按比例缩放时一并保留，不要将画布裁到笔画边缘。
- 建议起点：横版整体宽度至少 320 px；竖版整体宽度至少 240 px；双语字标宽度至少 280 px；紧凑字标宽度至少 160 px；独立灯泡整体高度至少 64 px。以上是本套交付的使用建议，最终以实际屏幕或打样清晰度为准。
- 16–48 px 的极小位置使用 favicon 专用 X 图标，不硬塞中文或 AI 小字。该图标提取自确认稿中的 X 字形及绿色切角，仅用于小尺寸识别，不能代替正式完整标志。
- 不要拉伸、旋转、擅自加阴影／描边、改变色值或移动 AI 上标。

## 文件说明

### 01_PNG_透明底
- 20 个 RGBA PNG，最长边均为 3000 px，保持比例，包含留白。
- “3000”表示最长边，不表示所有横版文件均为 3000 px 高。
- PNG 带有 300 dpi 元数据；放大或印刷排版仍优先使用 SVG。
- ColorLight = 浅底彩色；ColorDark = 深底彩色；MonoBlack = 纯黑；MonoWhite = 纯白。
- 白色版本在白底查看器里不可见或只看到彩色部分是正常现象，请用深色背景检视。

### 02_SVG_矢量描摹
- 20 个 SVG，全部是可缩放的路径，不内嵌位图，不引用外部字体。
- 基于上一轮横版确认图进行轮廓描摹、几何规整和纯色化，并用统一组件构建其它组合。它们是本次重建的路径母版，不是原设计软件的原生 .ai／.eps 源文件，也不是可编辑字体的文字对象。
- 轮廓描摹会对生成图的细微像素边缘作平滑处理，灯泡条带以规则圆角和直线切口重建；历史参考图已原样保留，便于比对。
- 生产使用以这些 SVG 及其导出的正式 PNG 为准；概念示意图仅供视觉参考。

### 03_背景预览
- 20 个 PNG，最长边 1800 px。
- 浅底彩色／纯黑置于白底；深底彩色／纯白置于 #171A1F。
- 这些文件是效果预览，底色不是透明的。

### 04_应用图标
- 浅底／深底头像：1024 px、512 px PNG 和 SVG。
- 浅底／深底小尺寸 X favicon：16、32、48、64、256 px PNG，SVG，以及包含 16 / 32 / 48 / 64 / 128 / 256 px 图层的 ICO。
- 头像和 favicon 文件自带背景，正方形画布，不预先烘焙圆角；可由网站或平台应用自己的形状遮罩。

### 05_确认稿与历史素材
- 用户原始标志 PNG：4 个，原样保存。
- 上一轮 AI 设计图：4 个，原样保存。
- 本轮系统适配概念示意：1 个。示意图中可能存在生成式排版差异，请勿从示意图截图当作正式 logo。

## 交付边界

本包是 logo 及数字端基础适配文件，不包含完整 VI 手册、名片／导视／包装版式或动效标志。未提供经打样确认的 CMYK／专色色值；实体制作时应由供应商基于本套 SVG 做目标材料和工艺的打样。未执行商标可注册性检索。

本次处理保留参考文件，不覆盖用户原图。正式交付文件不含字体文件。
